# Student Planner

A beginner-friendly student task and study planner built with HTML, CSS and JavaScript.

## Features
- Add tasks with a subject, due date and priority
- Mark tasks as completed
- Filter all, pending and completed tasks
- Delete tasks
- View total, completed and pending task counts
- Saves tasks in the browser with localStorage
- Responsive layout for mobile and desktop

## How to run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Add your study tasks.

No installation or backend is required.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## GitHub Pages
To publish: open repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. GitHub will provide your live website link.
